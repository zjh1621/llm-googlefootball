# 各球员角色传球决策伪代码 (详细版)

本伪代码旨在模拟现代足球中，不同位置球员在持球时的传球决策过程。它融合了 `player_roles.md` 中定义的角色、`传球战术.md` 中详细阐述的战术逻辑，并直接关联了 `observation.md` 中定义的环境观测数据和动作指令。

**通用变量与函数 (基于 observation.md):**

- `obs`: 当前帧的原始观测数据对象。
- `active_player_index`: 当前受控球员的索引，来自 `obs.active`。
- `player_role`: 当前球员的角色，来自 `obs.left_team_roles[active_player_index]`。
- `player_pos`: 当前球员的坐标，来自 `obs.left_team[active_player_index]`。
- `get_pressure_level(player_pos, obs.right_team)`: 一个函数，通过计算最近的对手距离来评估压迫程度 (`高`, `中`, `低`)。
- `get_teammate_info(obs.left_team, obs.left_team_roles, ...)`: 一个函数，返回所有队友的详细信息列表，包括位置、角色、跑动方向、被盯防状态等。
- `is_in_attacking_third(player_pos)`: 一个函数，判断球员是否在进攻三区。

## `e_PlayerRole_GK` (0: 守门员) 传球决策

```
FUNCTION decide_pass_GK(obs, active_player_index):
    // 核心职责：安全第一，兼顾进攻发起
    player_pos = obs.left_team[active_player_index]
    pressure = get_pressure_level(player_pos, obs.right_team)

    // 1. 高压情况
    IF pressure == '高':
        // 寻找最安全的短传出球点
        safest_short_pass_target = find_closest_unmarked_defender(obs)
        IF safest_short_pass_target EXISTS:
            RETURN action_short_pass // 11: 优先短传给空位后卫
        ELSE:
            // 短传风险高，则长传找前场
            long_pass_target = find_forward_target(obs, target_role=['CF'])
            IF long_pass_target EXISTS:
                RETURN action_long_pass // 9: 长传找前场支点
            ELSE:
                RETURN clear_ball() // 模拟解围，可映射为向边路的长传
            ENDIF
        ENDIF

    // 2. 无压或低压情况
    ELSE:
        // 寻找发动快速反击的机会
        counter_attack_target = find_teammate_exploiting_high_line(obs)
        IF counter_attack_target EXISTS:
            RETURN action_high_pass // 10: 精准高球发动奇袭

        // 默认地面组织
        ground_build_up_target = find_best_short_pass_to_CB_or_FB(obs)
        IF ground_build_up_target EXISTS:
            RETURN action_short_pass // 11: 短传给后卫，发动地面组织
        ENDIF

        // 最终选择：最稳妥的传球
        RETURN action_short_pass // 11: 短传给最近的后卫
    ENDIF
ENDFUNCTION
```

## `e_PlayerRole_CB` (1: 中后卫) 传球决策

```
FUNCTION decide_pass_CB(obs, active_player_index):
    // 核心职责：防守稳固，并作为进攻的第一发起点
    player_pos = obs.left_team[active_player_index]
    pressure = get_pressure_level(player_pos, obs.right_team)

    // 1. 应对高位逼抢
    IF pressure == '高':
        break_press_target = find_short_pass_to_DM_or_fullback(obs)
        IF break_press_target EXISTS:
            RETURN action_short_pass // 11: 快速短传打破逼抢
        ELSE:
            long_pass_target = find_forward_target(obs, target_role=['CF', 'RM', 'LM'])
            RETURN action_long_pass // 9: 长传越过逼抢区域
        ENDIF

    // 2. 常规组织进攻
    ELSE:
        // A. 寻找最高价值的穿透性传球 (Line-Breaking Pass)
        penetrating_pass_target = find_teammate_between_lines(obs, target_role=['CM', 'AM'])
        IF penetrating_pass_target EXISTS:
            RETURN action_short_pass // 11: 向前穿透性传球，这是高风险高回报的选择

        // B. 寻找大范围转移的机会
        diagonal_switch_target = find_teammate_in_weak_side_space(obs, target_role=['LM', 'RM', 'LB', 'RB'])
        IF diagonal_switch_target EXISTS:
            RETURN action_high_pass // 10: 长对角线转移，撕扯防线

        // C. 安全控球
        safe_pass_target = find_teammate_by_role(obs, role='CB') // 传给中卫搭档
        IF safe_pass_target EXISTS:
            RETURN action_short_pass // 11
        ELSE:
            safe_pass_target = find_closest_teammate(obs, role=['LB', 'RB', 'DM'])
            RETURN action_short_pass // 11
        ENDIF
    ENDIF
ENDFUNCTION
```

## `e_PlayerRole_LB / e_PlayerRole_RB` (2/3: 左/右后卫) 传球决策

```
FUNCTION decide_pass_Fullback(obs, active_player_index):
    // 核心职责：提供宽度，参与攻防
    player_pos = obs.left_team[active_player_index]
    pressure = get_pressure_level(player_pos, obs.right_team)

    // 1. 在本方后场受压时
    IF is_in_defensive_third(player_pos) AND pressure == '高':
        safe_target = find_pass_to_CB_or_GK(obs)
        IF safe_target EXISTS:
            RETURN action_short_pass // 11: 回传
        ELSE:
            RETURN action_long_pass // 9: 沿边线解围
        ENDIF

    // 2. 进入中前场后的进攻决策
    ELSE:
        // A. 传中决策 (当在进攻三区时)
        IF is_in_attacking_third(player_pos):
            cutback_target = find_teammate_for_cutback(obs, position_zone='禁区弧顶')
            IF cutback_target EXISTS:
                RETURN action_short_pass // 11: 执行倒三角传球

            cross_target = find_best_target_in_box(obs)
            IF cross_target EXISTS:
                IF cross_target.position == '前点':
                    RETURN action_short_pass // 11: 低平球传中
                ELSE:
                    RETURN action_high_pass // 10: 高球/弧线传中
                ENDIF
            ENDIF
        ENDIF

        // B. 检查与边锋或中场的配合
        combo_target = find_closest_teammate(obs, role=['LM', 'RM', 'CM'])
        IF combo_target EXISTS AND combo_target.movement == '前插': // 套边
             RETURN action_short_pass // 11: 为前插队友送出直塞
        ENDIF

        // C. 内切型决策
        IF player.role_tendency == '内切型' AND is_in_central_corridor(player_pos):
            central_pass_target = find_teammate_between_lines(obs, role=['CF', 'AM'])
            IF central_pass_target EXISTS:
                RETURN action_short_pass // 11: 从中路发动进攻
            ENDIF
        ENDIF
        
        // D. 默认选择：与附近队友进行安全配合
        safe_combo_target = find_closest_teammate(obs, role=['LM', 'RM', 'CM', 'CB'])
        RETURN action_short_pass // 11
    ENDIF
ENDFUNCTION
```

## `e_PlayerRole_LW / e_PlayerRole_RW` (边锋) 传球决策

*(此角色对应于 LM/RM 在进攻三区的行为)*

FUNCTION decide_pass_Winger(obs, active_player_index):
    // 核心职责：单点爆破，传中，内切创造机会
    player_pos = obs.left_team[active_player_index]
    
    // 仅在进攻三区应用此逻辑
    IF is_in_attacking_third(player_pos):
        // 1. 优先考虑内切射门
        IF can_cut_inside_and_shoot(player_pos, obs.right_team):
            RETURN action_shot // 12: 内切射门

        // 2. 其次考虑高价值的倒三角传球
        cutback_target = find_teammate_for_cutback(obs, role=['AM', 'CM'])
        IF cutback_target EXISTS:
            RETURN action_short_pass // 11: 倒三角传球
        
        // 3. 传中
        cross_target = find_best_target_in_box(obs, role=['CF', 'AM'])
        IF cross_target EXISTS:
            IF cross_target.position == '前点':
                RETURN action_short_pass // 11: 低平球传中
            ELSE:
                RETURN action_high_pass // 10: 高球传中
            ENDIF
        ENDIF

        // 4. 与边后卫或中场进行配合
        combo_target = find_closest_teammate(obs, role=['LB', 'RB', 'CM'])
        IF combo_target EXISTS:
            RETURN action_short_pass // 11: 短传配合
        ENDIF
    ENDIF

    // 如果不在进攻三区，则退化为CM/LM/RM的逻辑
    RETURN decide_pass_CM(obs, active_player_index)
ENDFUNCTION
```

## `e_PlayerRole_DM` (4: 防守型中场) 传球决策

```
FUNCTION decide_pass_DM(obs, active_player_index):
    // 核心职责：掌控节奏，连接攻防
    // 1. 优先向前传球，打破阵型
    forward_pass_target = find_teammate_between_lines(obs, role=['AM', 'CM', 'CF_回撤'])
    IF forward_pass_target EXISTS:
        RETURN action_short_pass // 11: 向前传球

    // 2. 大范围转移
    switch_play_target = find_teammate_in_weak_side_space(obs, role=['LM', 'RM', 'LB', 'RB'])
    IF switch_play_target EXISTS:
        RETURN action_long_pass // 9: 长传转移

    // 3. 安全控球
    safe_target = find_closest_unmarked_teammate(obs, role=['CB', 'CM', 'LB', 'RB'])
    RETURN action_short_pass // 11: 安全短传
ENDFUNCTION
```

## `e_PlayerRole_CM / LM / RM` (5/6/7: 中前卫/中场) 传球决策

```
FUNCTION decide_pass_CM(obs, active_player_index):
    // 核心职责：攻防枢纽，推进，创造
    // 如果在进攻三区的边路，使用边锋逻辑
    IF is_in_attacking_third(obs.left_team[active_player_index]) AND is_on_flank(obs.left_team[active_player_index]):
        RETURN decide_pass_Winger(obs, active_player_index)
    ENDIF
    
    // 1. 寻找致命直塞球
    through_ball_target = find_teammate_making_run_behind_defense(obs, role=['CF', 'LM', 'RM'])
    IF through_ball_target EXISTS:
        RETURN action_short_pass // 11: 直塞球

    // 2. 推进与配合 (二过一)
    one_two_target = find_teammate_for_one_two(obs, role=['CF', 'AM'])
    IF one_two_target EXISTS:
        RETURN action_short_pass // 11: 二过一

    // 3. 分边
    pass_to_wing_target = find_open_winger_or_fullback(obs)
    IF pass_to_wing_target EXISTS:
        RETURN action_short_pass // 11: 分边

    // 4. 默认：安全传球
    safe_target = find_closest_unmarked_teammate(obs, role=['DM', 'CB'])
    RETURN action_short_pass // 11
ENDFUNCTION
```

## `e_PlayerRole_AM` (8: 攻击型中场) 传球决策

```
FUNCTION decide_pass_AM(obs, active_player_index):
    // 核心职责：创造决定性机会
    // 1. 优先考虑自己射门
    IF is_in_shooting_range(obs.left_team[active_player_index]):
        RETURN action_shot // 12

    // 2. 寻找致命直塞 (最后一传)
    final_ball_target = find_teammate_making_run_behind_defense(obs, role=['CF', 'LM', 'RM'])
    IF final_ball_target EXISTS:
        RETURN action_short_pass // 11: 致命直塞

    // 3. 半场空间传中
    IF is_in_half_space(obs.left_team[active_player_index]):
        cross_target = find_best_target_in_box(obs, role=['CF'])
        IF cross_target EXISTS:
            RETURN action_high_pass // 10: 半场空间传中
        ENDIF
    ENDIF

    // 4. 耐心配合
    combo_target = find_closest_unmarked_teammate(obs, role=['CM', 'LM', 'RM'])
    RETURN action_short_pass // 11: 回传或分边，重新组织
ENDFUNCTION
```

## `e_PlayerRole_CF` (9: 中锋) 传球决策

```
FUNCTION decide_pass_CF(obs, active_player_index):
    // 核心职责：终结进攻，或作为支点
    player_pos = obs.left_team[active_player_index]

    // 1. 在禁区内，优先射门
    IF is_in_penalty_box(player_pos):
        IF has_good_shooting_angle(player_pos):
            RETURN action_shot // 12
        ELSE:
            // 射门角度不佳，寻找位置更好的队友
            better_shooter = find_teammate_in_better_shooting_position(obs)
            IF better_shooter EXISTS:
                RETURN action_short_pass // 11: 横传
            ELSE:
                RETURN action_shot // 12: 强行射门
            ENDIF
        ENDIF
    ENDIF

    // 2. 禁区外，根据角色倾向决策
    // A: 支点型
    IF player.role_tendency == '支点型':
        layoff_target = find_onrushing_midfielder(obs, role=['AM', 'CM'])
        IF layoff_target EXISTS:
            RETURN action_short_pass // 11: 做球
        ELSE:
            RETURN hold_up_play() // 护球，等待支援 (可映射为 action_dribble)
        ENDIF

    // B: 灵活型 (回撤)
    IF player.role_tendency == '灵活型':
        pass_to_runner = find_teammate_running_into_space_created_by_player(obs)
        IF pass_to_runner EXISTS:
            RETURN action_short_pass // 11: 为跑位的队友传球
        ELSE:
            // 参与中场配合
            combo_target = find_closest_unmarked_teammate(obs, role=['AM', 'CM'])
            RETURN action_short_pass // 11
        ENDIF
    ENDIF
ENDFUNCTION
